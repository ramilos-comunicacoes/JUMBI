{% if module == 'matters' %}

Uma pasta reúne a demanda

  1. Vincule a pessoa atendida e escolha o nicho.
  2. Use a pasta para reunir processos, tarefas, prazos e arquivos da mesma demanda.
  3. Em uma pasta sigilosa, confira o responsável e as pessoas autorizadas.
{% elif module == 'contacts' %}

Cadastre uma vez

  1. Busque a pessoa antes de criar outro cadastro.
  2. Informe o telefone com DDD e a data de nascimento, quando houver.
  3. Vincule a pessoa como cliente em uma pasta para acompanhar seu aniversário no calendário.
{% elif module == 'cases' %}

Processo dentro da pasta

  1. Selecione a demanda à qual o processo pertence.
  2. Informe número, órgão e parte contrária para facilitar a consulta.
  3. Atualize as informações manualmente; não há captura de andamentos dos tribunais.
{% elif module == 'tasks' %}

Do planejamento à entrega

  1. Defina quem executa, a prioridade e a data de entrega interna.
  2. Acompanhe o andamento no Kanban.
  3. Ao concluir, registre o que foi entregue. Prazos jurídicos têm cumprimento separado.
{% elif module == 'deadlines' %}

Registrar, conferir, cumprir

  1. Informe a fonte e o vencimento conferido pela equipe. O sistema não calcula o prazo jurídico.
  2. Use Conferir para confirmar obrigação, data e responsável.
  3. Registre o cumprimento com evidência. Alterar o vencimento exige motivo e nova conferência.
{% elif module == 'appointments' %}

Reserve o horário

  1. Escolha a categoria e informe início e término.
  2. Indique o local ou link da reunião e o responsável.
  3. O compromisso aparece no calendário. Obrigações jurídicas devem ser cadastradas em Prazos.
{% elif module == 'documents' %}

Preserve cada versão

  1. Vincule o arquivo à pasta correta e use um nome fácil de localizar.
  2. Para atualizar o conteúdo, envie uma nova versão: a anterior fica preservada.
  3. Enviar um arquivo não o publica ao cliente. No Max, use Revisão e portal para aprovar e compartilhar.
{% elif module == 'finance' %}

Previsão e movimentação

  1. Separe receita, despesa e valor de cliente.
  2. O valor previsto só é movimentado quando você registra uma baixa.
  3. Um estorno exige motivo e preserva o histórico. Para várias parcelas, use Honorários.
{% elif module == 'crm' %}

Defina o próximo contato

  1. Vincule a pessoa e informe a etapa do atendimento.
  2. Deixe clara a próxima ação e quem a executa.
  3. A estimativa não gera receita no financeiro. Ao marcar como perdida, registre o motivo.
{% else %}

Confira antes de salvar

Revise os dados e os campos obrigatórios. A ação será registrada no escritório selecionado.

{% endif %}
